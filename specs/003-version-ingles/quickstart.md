# Quickstart: validar la versión en inglés

1. `npm ci && npm test && npm run build && npm run dev`.
2. Abrir `#/?lang=en`: Inicio en inglés con "Choose your language" y los botones Español / English.
3. Recorrer Segmentos, Artículo, Impacto y Cómo usar con EN: sin texto de la interfaz en español.
4. Cifras de control en inglés: Impacto al 95 % → US$3.28M liberados, US$0.91M recuperados; por grupo
   US$0.55M + US$1.33M + US$1.40M; embudo 52%, US$21.86M y 75; FOODS_3_090 → US$114,538.
5. Pulsar ES en la barra superior: la misma página en español, con 3,28 M US$, 0,91 M US$, etc.
6. Recargar: se mantiene el último idioma elegido.
7. `#/articulo`: "Elige un artículo" / "Choose a product" con el buscador grande; clic en la flecha
   abre la lista.
